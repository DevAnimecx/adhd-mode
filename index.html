The 10 rules

#RuleWhat it does
1Lead with the next actionFirst line = something you can do now
2Number multi-step tasksNumbered list, one bounded action per step
3End with one concrete next actionOne thing under 2 min
4Suppress tangentsFinish first, offer second separately
5Restate state every turn"Step 3 of 5 done. Next: X."
6Scope by shape, not timeQuick / Medium / Large — not "15 min"
7Make wins visibleShow what works, concretely
8Matter-of-fact errorsNo "uh oh." Cause + fix.
9Cap lists at 5 itemsSplit into "now" vs "later"
10No preamble, no recap, no closersStart with answer, end when done

Plus a pre-send check (5 deletions before sending) and 6 override conditions (when to break the rules). Full text in every rule file on GitHub.

Frequently asked questions

What is adhd-mode?

adhd-mode is an open-source project that ships 10 output rules making AI coding assistants produce ADHD-friendly output. You place a single AGENTS.md file in your repository root, and every AI coding tool that reads it — Codex, Cursor, GitHub Copilot, Windsurf, Gemini CLI, Aider, Zed, and 20+ others — automatically shapes its output to be action-first, numbered, and free of preamble. The rules are adapted from i-have-adhd (MIT).

How is adhd-mode different from i-have-adhd?

i-have-adhd is a skill you invoke each session. adhd-mode is always on. It also fixes three problems users reported: rule decay (rules stop working after a few turns), fabricated time estimates, and bloat. adhd-mode covers Copilot, Windsurf, and Gemini that the original doesn't fully support.

Does adhd-mode stop working after a few turns?

No. adhd-mode includes an anti-decay mechanism: explicit re-injection instructions that tell the agent to re-apply all rules when the user says "adhd mode" again. This addresses the #1 complaint about the original.

Do I need an ADHD diagnosis to use this?

No. The rules help anyone who wants action-first, no-filler AI output. adhd-mode also works under the neutral name "action-first mode."

Why doesn't adhd-mode use time estimates?

The #3 complaint about the original was that the model fabricates inaccurate time estimates. adhd-mode replaces them with scope-by-shape: Quick (one file), Medium (2-3 files), Large (cross-cutting).

Which tools are supported?

Codex, Cursor, GitHub Copilot, Windsurf, Gemini CLI, Claude Code, Aider, Zed, Factory, Jules, Devin, Amp, and 20+ others via AGENTS.md.

Is adhd-mode free?

Yes. MIT licensed, no paid features, no accounts, no telemetry.

How do I turn it off?

Say "stop adhd mode" or "normal mode" in any chat. The AI returns to its default output style.

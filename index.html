The 10 rules

Each rule addresses a specific ADHD cognitive challenge. Full text in every rule file on GitHub.

#RuleWhat it doesADHD challenge addressed
1Lead with the next actionFirst line = something you can do nowTask initiation paralysis
2Number multi-step tasksNumbered list, one bounded action per stepOverwhelm from unbounded scope
3End with one concrete next actionOne thing under 2 minDecision fatigue at end of response
4Suppress tangentsFinish first, offer second separatelyAttention switching cost
5Restate state every turn"Step 3 of 5 done. Next: X."Working memory limits
6Scope by shape, not timeQuick / Medium / Large — not "15 min"Fabricated estimates cause distrust
7Make wins visibleShow what works, concretelyDopamine deficit — progress must be visible
8Matter-of-fact errorsNo "uh oh." Cause + fix.Emotional dysregulation from errors
9Cap lists at 5 itemsSplit into "now" vs "later"Choice paralysis from long lists
10No preamble, no recap, no closersStart with answer, end when doneScrolling fatigue from filler

Frequently asked questions

What is adhd-mode?

adhd-mode is an open-source project that ships 10 output rules making AI coding assistants produce ADHD-friendly output. You place a single AGENTS.md file in your repository root, and every AI coding tool that reads it — Codex, Cursor, GitHub Copilot, Windsurf, Gemini CLI, Aider, Zed, and 20+ others — automatically shapes its output to be action-first, numbered, and free of preamble. The rules are adapted from i-have-adhd (MIT).

How is adhd-mode different from i-have-adhd?

i-have-adhd is a skill you invoke each session. adhd-mode is always on — you paste one file and every response is ADHD-shaped from the first message. It also fixes rule decay, fabricated time estimates, and bloat. adhd-mode covers Copilot, Windsurf, and Gemini that the original doesn't fully support.

How do I install adhd-mode?

Run: curl -O https://raw.githubusercontent.com/DevAnimecx/adhd-mode/main/AGENTS.md — then restart your editor. Or use the installer: curl -sSL https://raw.githubusercontent.com/DevAnimecx/adhd-mode/main/install/install.sh | bash

Which tools does adhd-mode support?

Codex, Cursor, GitHub Copilot, Windsurf, Gemini CLI, Claude Code, Aider, Zed, Factory, Jules, Devin, Amp, RooCode, and 20+ others via AGENTS.md.

Does adhd-mode stop working after a few turns?

No. adhd-mode includes an anti-decay mechanism: explicit re-injection instructions. Say 'adhd mode' again and the AI re-applies all rules from scratch.

Do I need an ADHD diagnosis?

No. The rules help anyone who wants action-first, no-filler AI output. Also works as 'action-first mode.'

Why doesn't adhd-mode use time estimates?

The #3 complaint about the original was fabricated estimates. adhd-mode uses scope-by-shape: Quick, Medium, Large.

Is adhd-mode free?

Yes. MIT licensed. No paid features, accounts, or telemetry.

ADHD-friendly output rules for Gemini CLI

ADDD-friendly output rules for Gemini CLI. Make Gemini lead with action, number steps, and stop over-explaining. One GEMINI.md file at project root. One file. Always on. No slash command. No plugin marketplace.

What this does

Gemini CLI is a powerful AI coding tool, but it buries answers behind preamble, tangents, and closing pleasantries. adhd-mode fixes this by placing one file that Gemini CLI reads automatically, shaping every response to be action-first, numbered, and free of filler.

⚡

Action-first

First line = something you can do now. Not context. Not a plan. The action.

🔢

Numbered steps

Multi-step tasks become numbered lists with one bounded action per step.

🔁

Anti-decay

Rules persist across turns with explicit re-injection. No fading after 5 turns.

📐

Scope by shape

Quick / Medium / Large instead of fabricated time estimates.

Install for Gemini CLI

Gemini CLI reads GEMINI.md files hierarchically: global (~/.gemini/GEMINI.md), project root (./GEMINI.md), and subdirectory (JIT context). All found files are concatenated and sent with every prompt. You can also configure Gemini CLI to read AGENTS.md instead via .gemini/settings.json.

Gemini CLI install
curl -O https://raw.githubusercontent.com/DevAnimecx/adhd-mode/main/rules/gemini/GEMINI.md

Or use the universal AGENTS.md file

curl -O https://raw.githubusercontent.com/DevAnimecx/adhd-mode/main/AGENTS.md

The file is at rules/gemini/GEMINI.md. Restart Gemini CLI after installing.

How Gemini CLI loads the rules

Technical details on how Gemini CLI discovers and applies the output rules.

Gemini CLI reads GEMINI.md files hierarchically: global (~/.gemini/GEMINI.md), project root (./GEMINI.md), and subdirectory (JIT context). All found files are concatenated and sent with every prompt. You can also configure Gemini CLI to read AGENTS.md instead via .gemini/settings.json.

The file uses Gemini CLI's native rule-loading mechanism. Once placed at the correct path, Gemini CLI reads it on startup and applies the rules to every AI interaction — chat, inline completions, and code generation. The rules stay on until you say "stop adhd mode" in chat.

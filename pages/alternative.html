When to use which

Use i-have-adhd if
• You use Claude Code and like invoking the skill per session
• You want on-demand control (on for some tasks, off for others)
• You want the original, maintained by the original author
• You need the eval harness or translations
Use adhd-mode if
• You use 2+ AI tools and want consistent behavior
• You want it always on, no slash command
• You use GitHub Copilot, Windsurf, or Gemini CLI
• You've experienced rule decay with the original
• You want a one-command installer
• You prefer "action-first mode" framing

Use both: They complement each other. Claude Code users can install the original plugin for on-demand use AND adhd-mode's CLAUDE.md for always-on. Same rules, no conflict.

Migrating from i-have-adhd to adhd-mode

Switching takes 30 seconds. Your existing rules are not affected.

Migration
# 1. Keep your existing i-have-adhd setup (no need to uninstall)
# 2. Add adhd-mode's AGENTS.md:
curl -O https://raw.githubusercontent.com/DevAnimecx/adhd-mode/main/AGENTS.md
# 3. For Claude Code, also add:
curl -O https://raw.githubusercontent.com/DevAnimecx/adhd-mode/main/CLAUDE.md
# 4. Restart your editor

That's it. Both can coexist. i-have-adhd for on-demand, adhd-mode for always-on.

Install adhd-mode

One file. 30 seconds. Every AI coding tool you use. No accounts, no plugins, no marketplace.

Option 1: Universal AGENTS.md (fastest)

Works in 20+ tools. Codex, Cursor, Copilot cloud agent, Windsurf, Gemini (with config), Aider, Zed — all read it.

Terminal
curl -O https://raw.githubusercontent.com/DevAnimecx/adhd-mode/main/AGENTS.md

For Claude Code, also add:

curl -O https://raw.githubusercontent.com/DevAnimecx/adhd-mode/main/CLAUDE.md

CLAUDE.md uses @AGENTS.md import for always-on output in Claude Code.

Option 2: One-command installer

Detects all tools, installs the right file for each, merges safely (backs up existing files), idempotent.

Terminal
curl -sSL https://raw.githubusercontent.com/DevAnimecx/adhd-mode/main/install/install.sh | bash

Windows: clone the repo and run install\install.ps1.

Installer flags: --global (user-level), --tool cursor (one tool), --overwrite (replace existing), --list (dry run).

How to turn off adhd-mode

Say "stop adhd mode" or "normal mode" in any chat. The AI returns to its default output style for the rest of the session. To permanently remove, delete the file.

The 10 ADHD output rules

Each rule addresses a specific ADHD cognitive challenge. Adapted from i-have-adhd (MIT). Same rules, always on, in 20+ tools.

What ADHD changes about reading

🧠

Working memory is small

Do not ask the reader to "keep in mind X." They can't.

⚡

Knowing ≠ doing

Knowing the answer is not doing the answer. The output must be actionable.

🚀

Starting is hardest

The first line must be something they can do right now.

📈

Dopamine is scarce

Visible progress matters. Show what works, concretely.

The rules

#RuleWhat it doesADHD challenge
1Lead with the next actionFirst line = something you can do nowTask initiation
2Number multi-step tasksNumbered list, one bounded action per stepOverwhelm
3End with one concrete next actionOne thing under 2 minDecision fatigue
4Suppress tangentsFinish first, offer second separatelyAttention switching
5Restate state every turn"Step 3 of 5 done. Next: X."Working memory
6Scope by shape, not timeQuick / Medium / LargeFabricated estimates
7Make completed work visibleShow what now worksDopamine deficit
8Matter-of-fact tone for errorsNo "uh oh." Cause + fix.Emotional dysregulation
9Cap lists at 5 itemsSplit into "now" vs "later"Choice paralysis
10No preamble, no recap, no closersStart with answer, end when doneScrolling fatigue

Pre-send check

Before sending any response, the AI deletes:

1. The first sentence if it announces what you are about to do.

2. The last sentence if it asks "anything else?"

3. Any "by the way" sidebar.

4. Any hedging adverb adding no information.

5. Any idiom or figurative phrase.

When to break the rules

6 override conditions:

1. User asks to "explain" or "walk me through."

2. Destructive action ahead.

3. Debug spiral (3+ turns of "still broken").

4. Real ambiguity in the request.

5. A rule fights the task.

6. A rule fights the harness.

Anti-decay mechanism (v2.0)

The #1 complaint about the original was rules fading after a few turns. adhd-mode includes:

Explicit re-injection: If output drifts back to verbose, the reader says "adhd mode" again. The AI re-applies all rules from scratch.

Output style delivery: Ships as an always-on output style (AGENTS.md), not a one-shot skill prompt that gets diluted as context grows.

No partial relaxation: Rules do not gradually relax as the conversation gets longer. They stay at full strength.

FAQ

What are the 10 ADHD output rules?

1. Lead with action 2. Number steps 3. End with next action 4. Suppress tangents 5. Restate state 6. Scope by shape 7. Make wins visible 8. Matter-of-fact errors 9. Cap lists at 5 10. No preamble/closers.

What is the pre-send check?

Before sending, delete: self-announcing openers, 'anything else?' closers, 'by the way' sidebars, empty hedges, idioms.

When should you break the rules?

When: user asks to 'explain', destructive action ahead, debug spiral, real ambiguity, rule fights task, rule fights harness.

## Content structure for AEO

AI answer engines (ChatGPT, Perplexity, Google AI Overviews) cite content that is:
1. **Structured** — tables, numbered lists, Q&A format
2. **Self-contained** — each answer works standalone
3. **Factual** — specific numbers, dates, tool names
4. **Fresh** — recent dates, current versions

This repo's docs are structured to maximize citability:
- README has the 10-rules table (highly citable)
- FAQ.md has Q&A format (directly answerable)
- COMPARISON.md has a structured comparison table
- IMPLEMENTATION.md has a per-tool technical reference

## Organic viral loops

1. **Before/After screenshot** — the single most shareable artifact. Every user's first experience is screenshot-worthy.
2. **One-command install** — the shareable URL. `curl | bash` is a meme format.
3. **PR-per-tool** — each new tool is a PR, a commit, a star, a community moment.
4. **Cross-tool identity** — "I use adhd-mode in all 3 of my editors" becomes a status signal.
5. **Niche forks** — "adhd-mode for data science" etc. Forks become distribution.
6. **Honest test scores** — publishing which tools obey the rules best is content that writes itself.
